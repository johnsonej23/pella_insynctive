## Pella Insynctive

This integration is designed to work with a Pella Insynctive Bridge (2nd Generation).  You will need to know the IP address of the bridge and have it connected to your wired network.  This integration works via the telnet interface built into the bridge.  It is recommended to set a DHCP reservation on your router/DHCP server so that it will always get the same IP address.  If it's IP address changes, you will need to reconfigure the bridge in Home Assistant with the new address.
