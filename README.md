## Pella Insynctive

This integration is designed to work with a Pella Insynctive Bridge (2nd Generation) and its associated sensors and window coverings.  You will need to know the IP address of the bridge and have it connected to your wired network.  This integration works via the telnet interface built into the bridge.  It is recommended to set a DHCP reservation on your router/DHCP server so that it will always get the same IP address.  If it's IP address changes, you will need to reconfigure the bridge in Home Assistant with the new address.

I have not tested this with a 1st Generation or 3rd Generation Bridges.  If someone has one of these and would like to use this integration with it, please let me know.
